# Hotel-and-Resort-Database-Management
## About the Project
This is a group project focused on creating a database system for a hotel and resort using Oracle APEX.

The system helps manage hotel information, including guests, employees, rooms, reservations, services, and payments.

## Team Members
- Kanravi Charoentanaset
- Thu Ta Naing

## Project Features
- Manage guest information
- Manage employee information
- Manage room types and room details
- Manage reservations
- Manage hotel services
- Manage payment information
- View data through reports and charts

## Technologies Used
- Oracle APEX
- SQL
- Oracle Database

## Project Type
University Group Project

## Team Project
This project was developed as part of a university course.
